    02

    Add your context

    Email, authentication fields and cookies are checked automatically. Add names or domains you want kept private; both fields are optional.

    Enter a customer name, internal project name or phrase you want kept private, one per line. Literal, case-insensitive matching within a line; no automatic judgment. Chinese terms work in text files; image OCR currently reads English.

    For the original sample, enter northstar.test. For your files, enter an internal domain only, without https:// or a path, one per line or comma separated. Includes subdomains and emails on those domains.

    Optional: session cookie names

    Only enter cookie names, never their values. Other populated cookies generate a review warning.

    File bytes go only to the process on this computer. Nothing is sent to a cloud service.
