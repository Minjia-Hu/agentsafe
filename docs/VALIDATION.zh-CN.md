## README 演示与 pipx——2026 年 10 月 25 日

- macOS 上用 pipx 1.18.4、`--backend pip` 和 Python 3.12.12，将 `git+https://github.com/Minjia-Hu/agentsafe.git@v0.1.0a1`（提交 `be1434f`）装入隔离的临时 pipx 目录。未修改全局 Python 或终端配置。这验证 Git 源码安装，不是 PyPI 发布。无需额外指定路径即可找到已有的 Tesseract 5.5.2 / `eng`。
- 在仓库外运行已安装命令，`doctor` 和 `demo --no-open` 通过：原始样本 4 HIGH / 2 WARN，预制修改后样本 0 HIGH / 1 WARN，已知 OCR 漏检仍标明需人工审阅。演示整体按文档返回 0。
- pipx 安装的 GUI 在 Chromium 中完成中英文流程：选择打包的虚构 `business-context.png` 和 `.log`，配置三个样本短语，查看 5 个 HIGH，手动勾选第一个图片区域，再拖动矩形遮盖第二处，生成/重检一张 PNG 并下载。下载字节与重检的数据完全一致、原件未改，未观察到浏览器脚本错误或对外请求，两次会话均已结束。
- 将最初的八张截图轮播替换为中英文已安装版本的连续浏览器录屏。每个 GIF 约 22.5 秒、338 帧、15 fps、960 × 675，小于 6.5 MB。可看到鼠标移动、点击反馈、滚动和真实拖动遮盖。添加了仅用于录制的鼠标/点击标记，未改变应用代码或结果；只裁去准备与结束会话部分，未伪造应用状态，未使用私密材料。时长用于演示，不是性能基准。未录制系统选文件窗口，首帧显示已选文件和明确配置，使用指南保留静态步骤截图。
- 最初自动选择的 uv 后端因 TLS 连接失败而无法下载构建依赖，明确使用 pip 后端后成功，没有降低 TLS 校验。这不说明 uv 普遍不兼容。未实测 `pipx ensurepath`/新终端行为，也未从零安装 Homebrew/Python/OCR；前置环境已存在。Windows 与更广泛浏览器验证仍待完成。

## 公开前修复 — 2026 年 10 月 25 日

- 增加带引号标量与等号分隔的认证/Cookie 字段识别。虚构回归覆盖独立检测、同一行多个字段、转义引号、空值/占位符、原始位置、两种审阅渲染的遮盖，以及无法确定边界时不保留行片段。问题位置仍显示但不可点击；这不是完整 JSON/HAR 文档解析。
- 静态资源请求和被拒绝的 API 请求不再续期 GUI 闲置保留时间；安装包移除设计对比路由与未采用的候选素材。
- Pillow 提升为 `>=13,<14`，参考环境使用 13.0.0。[上游 PNG EXIF 公告](https://github.com/python-pillow/Pillow/security/advisories/GHSA-g4qv-2jxx-769h)涉及此前的 `getexif()` 路径；核实日期为 10 月 25 日，并非上游所有格式相关公告都适用于本项目的 PNG/JPEG 路径。
- 本机 172 个行为测试通过、零跳过。新建 macOS Python 3.12.12 环境从源码安装成功；源码包/wheel 构建，以及在仓库外的已安装 wheel doctor、虚构 demo、GUI/PNG 副本检查通过。独立环境使用 Tesseract 5.5.2 / English、Typer 0.27.3。
- 中英文浏览器检查通过：引号日志遮盖、歧义行回退、虚构客户/项目样本、两区域图片覆盖、重检、下载和结束会话，未观察到脚本错误。环境为参考 Mac 上的 Chromium，不代表全面浏览器认证。
- pip-audit 审查完整八项已解析运行依赖，未报告已知漏洞。CI 新增确切安装版本的依赖审查；Dependabot 每周提出 Python/Actions 更新。只查询公开依赖信息，不发送用户素材。
- 参考 Mac 的 uv Python 在审查工具创建临时复制环境时无法定位动态库，改为直接审查确切解析版本后通过。普通新建虚拟环境安装并运行 AgentSafe 成功；未在全新机器安装 Homebrew/Python/OCR，这一缺口仍保留。

实现候选 `c7b8a9b` 的三个平台 CI 任务与依赖安全任务全部通过；每个平台运行 172 个测试、零跳过，并构建和检查安装后的分发包。使用时请核对[对应提交的 CI](https://github.com/Minjia-Hu/agentsafe/actions/workflows/ci.yml)；下方原有矩阵保留为历史证据。

## 浏览器与扫描器证据

此前本地检查覆盖文件选择、无效上下文、旧结果提示、刷新恢复、图片条目选择、脱敏日志行高亮、手动像素坐标、撤销，以及两区域 PNG 副本/重检和下载链接。参考虚构结果为：原始样本 4 HIGH / 2 WARN，预制修改后样本 0 HIGH / 1 WARN，客户/项目样本 5 HIGH。OCR 版本可能改变个别匹配。

行为测试覆盖受支持阳性和正常边界、字面短语与中文日志、隐藏敏感值/转义、损坏/不支持/过大输入、OCR 缺失和空输出、认证、过期审阅 ID、原件不变、导出像素和会话生命周期。预期与已知模糊小图漏检见[样本标签](../examples/synthetic/README.zh-CN.md)。

## 剩余缺口

- 全新终端用户 Mac 安装，包括 Homebrew 设置。
- Windows 和矩阵之外的平台。
- 更广泛的浏览器/响应式表现、拖动框选手感及各浏览器下载体验。
- 独立可用性、重复使用、现实误报/漏报率与市场需求。

已提供带版本标签的源码 Alpha；这些检查不证明支持独立安装包、达到生产就绪或具备现实准确率。
