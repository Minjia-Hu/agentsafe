# Alpha 发布清单

[English](ALPHA_RELEASE.md)

候选：**0.1.0a1**，采用 MIT 许可的源码 Alpha。准备工作不会创建标签、发布版本/软件包或改变仓库可见性。

## 候选范围

本地浏览器 GUI 与 CLI 检查明确选择的 PNG/JPEG 截图和 UTF-8 日志/文本；配置短语/域名与认证/Cookie 结构规则；隐藏敏感值的定位；手动不透明 PNG 副本、原策略重检与明确下载；虚构样本及 A 字标。

不包含独立安装包、云推理、自动打码、自动保密名称识别、更多格式/语言、Git hook 或上传拦截。版本说明应保留这些边界。

## 公开前

1. 审阅确切候选文件树、可达历史、许可证和两种语言的文档；新增产物与源码改动都需审阅。
2. 要求确切版本的三个 CI 环境全部通过，行为测试零跳过，分发包构建与安装后检查成功。[验证记录](VALIDATION.zh-CN.md) 提供证据和缺口，不能替代当前运行。
3. 确认维护者的公开决定；核对命名/分发说明，不引导安装归属不明的包名。
4. 如修改可见性，应启用 GitHub 私密漏洞报告并验证入口，再宣传该渠道。遵循 SECURITY.md，不在公开 issue 中索取真实敏感附件。
5. 发布获批后，只对已审阅版本创建 `v0.1.0a1` 预发布标签。源码 Alpha 可使用 GitHub 源码归档；注册服务发布与软件包附件需另外验证和批准。

## 预发布说明草案

AgentSafe 是实验性的本地截图与调试日志隐私检查工具，提供浏览器 GUI 与 CLI。定位受支持的敏感信号，在新 PNG 中手动遮盖图片区域，并在保存前重检同一副本。

按 README 从源码安装，试用虚构的「客户／项目名」样本；不需要真实私密文件。源码与原创项目素材采用 MIT 许可。

Alpha 支持可读英文图片文字与 UTF-8 日志，日志可以配置中文短语。OCR 与规则可能漏检，零发现不保证隐私，也不拦截 Git push/上传。已测环境与平台/体验缺口见验证记录。

欢迎具体的安装或审阅问题及小型虚构复现。漏洞通过 SECURITY.md 反馈。
