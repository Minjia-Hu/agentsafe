# Alpha 发布准备

[English](ALPHA_RELEASE.md)

准备日期：2026 年 10 月 18 日。候选软件包版本：**0.1.0a1**。本轮准备尚未创建公开版本/标签或上传软件包注册服务。仓库保持私有，等待最终发布决定。

## 发布范围

- 本地浏览器 GUI 与 CLI，检查明确选择的 PNG/JPEG 截图和 UTF-8 日志/文本。
- 配置的敏感短语/域名、认证/Cookie 结构检查，以及隐藏敏感值的问题说明与位置。
- 手动遮盖图片区域、生成新 PNG、沿用原策略重检并明确下载。
- 内置虚构样本和已知 OCR 漏检案例，默认采用 A 字标。
- MIT 许可的源码安装、中英文说明、贡献/安全指南与 CI。

Alpha 不包含独立 Mac 安装包、云扫描、更多格式/语言、自动敏感名称识别、自动打码、Git hook 或上传拦截。版本说明应保留这些边界。

## 准备证据

最终的安装、测试、打包及仓库检查结果记录在 [VALIDATION.zh-CN.md](VALIDATION.zh-CN.md)。本机准备检查已记录；私有推送后验证远端 CI。本机测试不等于 GitHub Actions 或全新电脑验证。

## 最终发布步骤

1. 完成源码/wheel 检查、仓库内容和历史审阅，将准备结果提交并同步至现有私有远端。
2. 核对确切远端提交与 CI 结果；Linux 或更多 Python 版本的任务通过前，不宣称已验证。
3. 确认最终公开范围，包括 MIT 许可、已跟踪的中英文文档与全部已有提交历史。仅从最新文件树移除文件不会移除其历史。
4. 在所有者明确确认发布后，将仓库改为公开、启用 GitHub 私密漏洞报告，并在宣传安全反馈渠道前确认入口可用。
5. 为已审阅提交创建预发布，标签为 `v0.1.0a1`，采用下方说明。源码 Alpha 可仅提供 GitHub 源码归档，不承诺原生安装包。软件包附件需另行选定并验证后发布。

完成准备文档不代表已授权改写历史、改变可见性、创建版本或发布软件包。

## 拟议预发布说明

AgentSafe 是实验性的本地截图与调试日志隐私检查工具，提供浏览器 GUI 和 CLI。它定位受支持的敏感信号，让你手动遮盖截图区域、生成新的 PNG，并在保存之前重检同一副本。

按 README 从源码安装，然后试用虚构的「客户／项目名」样本。无需真实私密材料即可体验。源码与原创项目素材采用 MIT 许可。

此 Alpha 支持可读的英文图片文字及 UTF-8 日志，日志可配置中文短语。OCR 和已声明规则可能漏检，零发现不保证隐私，也不拦截 Git push 或上传。已测试环境及剩余体验/平台缺口见验证记录。

欢迎具体的安装或审阅反馈，请提供小型虚构复现。漏洞按 SECURITY.md 反馈。
